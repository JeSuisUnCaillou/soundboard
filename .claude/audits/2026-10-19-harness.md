## Findings

### 1. A PR with a merge conflict waits for a CI run that never comes

**Pillar**: constraints
**Evidence**: team memory line "CI gotcha (2026-10-17): a PR with a merge
conflict gets no `pull_request` e2e runs on new pushes". Thread "Show remove
zone on drag start": the owner validated at 14:43 ("tu pourras merge"), the
last status at 14:46 read "Waiting for CI to merge", and nothing happened
until the owner typed "merge" at 18:45. Thread "Fix medium bugs 16 to 19":
"Waiting for CI, then merging it" at 14:27, nudged by the coordinator at
14:55; main had to be merged into that branch three times. Seven threads
merged main in at least once because parallel threads conflicted.
**Remedy**: bring home — `review-loop/SKILL.md` step 7: before waiting for the
CI-green event, check the PR is mergeable and merge `main` in if not.
**Expected impact**: turns ending on "waiting for CI" that the owner or the
coordinator has to restart — baseline 2 in 16 threads, 2026-10-19 — expected
0 — check on 2026-10-26 — if not: a check in the Stop hook that refuses to
end a turn on a PR whose `mergeable_state` is `dirty`.
**Applied**: yes, commit "A PR that conflicts with main gets main merged in before CI is awaited"

### 3. A change reached further than its ask, and a later PR had to pull it back

**Pillar**: constraints
**Evidence**: PR #122 made two taps within 300 ms count as one on every pad;
the owner asked in the project chat at 23:46 for layering pads to be exempt,
which cost PR #130. PR #127 moved the hit/cue line to 10 s, which turned the
bundled 8.4 s Birds pad into a hit; the owner reported it on 2026-10-18 12:16,
which cost PR #133. Neither reviewer of the review loop is asked to look for
this.
**Remedy**: control — `review-loop/reviewers.md`, the bugs reviewer also
looks for behaviour the diff changes outside what its issue asked, the
bundled board included.
**Expected impact**: PRs whose only purpose is to undo part of an earlier
PR's reach — baseline 2 (#130, #133), 2026-10-19 — expected 0 — check on
2026-10-26 — if not: an e2e test that plays each bundled pad and checks it
behaves as `js/bundled.js` sets it up.
**Applied**: yes, commit "The bugs reviewer looks for behaviour changed beyond the ask"
